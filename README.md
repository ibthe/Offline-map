# Georgia Offline Map (Android)

Полностью офлайн-карта для поездок по Грузии. В APK нет разрешения INTERNET.

## Что умеет
* Подробная векторная карта OSM (дороги, тропы, здания, реки, леса, ледники, заповедники, границы, вершины с высотами, населённые пункты, POI), светлая и тёмная.
* Подписи на **грузинском, русском и английском**; каждый язык включается отдельно (Меню → Языки).
* **Поиск** городов, сёл, вершин, POI на трёх языках без интернета.
* **Категории POI**: АЗС, аптеки, больницы, банкоматы, магазины, еда, ночлег, вода, туалеты, парковки, транспорт, достопримечательности.
* **Рельеф**: тени гор (hillshade) и высота в точке под перекрестием.
* **GPS без сети** («Я здесь», статус на экране), **запись трека** в фоне (с уведомлением), **свои точки** (долгое нажатие или «+ Точка»), список точек и треков.
* **Линейка**, переход по координатам, копирование координат (тап по строке сверху).
* **Экспорт/импорт GPX** (точки и треки).
* **Разговорник** русский/английский/грузинский с транскрипцией; справка (112).
* **Диагностика** (Меню → Диагностика): размер данных, число тайлов, какие слои реально рисуются, ошибки загрузки.

## Как собрать
1. Залейте содержимое в репозиторий на github.com (ветка `main`).
2. Actions → Build APK → Run workflow. Первая сборка 30–60 минут (тайлы, индекс поиска, рельеф), потом данные берутся из кэша.
3. APK: страница запуска → Artifacts → `georgia-offline-map-apk`.

Сборка сама проверяет тайлы (`tools/check_tiles.py`): если в них нет воды, дорог, поселений или названий ka/ru/en, она останавливается с понятным сообщением.
При первом запуске приложение распаковывает данные во внутреннюю память (нужно свободное место примерно размером с APK).

## Дизайн и карта (v2.1)
* Новый интерфейс: стеклянные панели, круглые кнопки справа (вся Грузия, я здесь), нижняя панель «меню + добавить точку». Тема: Меню → «Тема» (как в системе / светлая / тёмная) переключает и интерфейс, и стиль карты.
* Водоёмы: швы между соседними полигонами закрываются (заливка без сглаживания + обводка того же цвета), пруды и водохранилища больше не «в клетку».
* Дороги: мосты, туннели (пунктир), грунтовки, пешеходные, односторонние стрелки, канатные дороги, пирсы, переходы между классами по масштабам.
* Ландшафт: виноградники, сады, кустарники, осыпи/скалы, ледники, луга, военные зоны, автостанции; мягче тени рельефа.

## Не включено
* Построение маршрутов по дорогам (офлайн-роутер) — отдельная большая задача.
* Горизонтали рельефа: есть только тени гор.
* Данные OSM актуальны на дату сборки; закрытие горных дорог зимой на карте не отражено.
