# Georgia Offline Map (Android)

Полностью офлайн-карта для поездок по Грузии. В APK нет разрешения INTERNET.

## Что умеет
* Подробная векторная карта OSM (дороги, тропы, здания, реки, леса, ледники, заповедники, границы, вершины с высотами, населённые пункты, POI), светлая и тёмная.
* Подписи на **грузинском, русском и английском**; каждый язык включается отдельно (Меню → Языки).
* **Поиск** городов, сёл, вершин, POI на трёх языках без интернета.
* **Категории POI**: АЗС, аптеки, больницы, банкоматы, магазины, еда, ночлег, вода, туалеты, парковки, транспорт, достопримечательности.
* **Рельеф**: тени гор (hillshade) и высота в точке под перекрестием.
* **GPS без сети** («Я здесь», статус на экране), **запись трека** в фоне (с уведомлением), **свои точки** (долгое нажатие или «+ Точка»), список точек и треков.
* **Линейка**, переход по координатам, копирование координат (тап по строке сверху).
* **Экспорт/импорт GPX** (точки и треки).
* **Диагностика** (Меню → Диагностика): размер данных, число тайлов, какие слои реально рисуются, ошибки загрузки.

## Как собрать
1. Залейте содержимое в репозиторий на github.com (ветка `main`).
2. Actions → Build APK → Run workflow. Первая сборка 30–60 минут (тайлы, индекс поиска, рельеф), потом данные берутся из кэша.
3. APK: страница запуска → Artifacts → `georgia-offline-map-apk`.

Сборка сама проверяет тайлы (`tools/check_tiles.py`): если в них нет воды, дорог, поселений или названий ka/ru/en, она останавливается с понятным сообщением.
При первом запуске приложение распаковывает данные во внутреннюю память (нужно свободное место примерно размером с APK).

## Дизайн и карта (v2.1)
* Новый интерфейс: стеклянные панели, круглые кнопки справа (вся Грузия, я здесь), нижняя панель «меню + добавить точку». Тема: Меню → «Тема» (как в системе / светлая / тёмная) переключает и интерфейс, и стиль карты.
* Водоёмы: швы между соседними полигонами закрываются (заливка без сглаживания + обводка того же цвета), пруды и водохранилища больше не «в клетку».
* Дороги: мосты, туннели (пунктир), грунтовки, пешеходные, односторонние стрелки, канатные дороги, пирсы, переходы между классами по масштабам.
* Ландшафт: виноградники, сады, кустарники, осыпи/скалы, ледники, луга, военные зоны, автостанции; мягче тени рельефа.

## Изменения v2.2
* Вокзалы и станции: ж/д вокзалы и платформы (красные точки), метро, автовокзалы (зелёные), паромные терминалы, канатные станции, трамвайные остановки. Это отдельные слои с подписями на выбранных языках, они видны всегда (с 12–14 масштаба) и не зависят от фильтра POI.
* Поиск: по слову «вокзал», «станция», «автовокзал», «метро», «паром», «station», «bus station» находятся все такие объекты; вокзалы выше обычных POI; «ё» = «е».
* Меню POI: «Транспорт» разделён на «Вокзалы и станции» и «Остановки и такси»; подписи типов в результатах поиска.
* Железные дороги: станционные и депо-пути показываются только вблизи, основные линии чище.
* Односторонние дороги: стрелки теперь и для обратного направления (oneway=-1).
* Исправлено: падение службы записи трека (stopSelf до startForeground).
* Сборка: кэш тайлов, индекса поиска и рельефа разделён. Раньше правка build_places.py не применялась, потому что restore-keys подтягивал старый places.db.

## Дизайн v2.3
* Экран под системными панелями (edge-to-edge): прозрачные статус-бар и навигация, панели сами отодвигаются от выреза и жестовой полосы; логотип, атрибуция и компас MapLibre не прячутся под панелями.
* Нижний плавающий док (меню + градиентная кнопка «Добавить точку»), справа одна стеклянная капсула «вся Грузия / я здесь».
* Поиск: крупная «пилюля», в результатах круглые значки и более читаемые заголовки; индиго-фиолетовый градиент акцента, светлая и тёмная палитры.
* Новая адаптивная иконка (с монохромным слоем для тем Android 13+).

## Типографика, сетка и цвет (v2.4)
* **Шрифты интерфейса:** единая шкала 20 / 16 / 15 / 14 / 12 (заголовок, название, текст, подпись), один шрифт для грузинского, русского и английского. Применена и к диалогам меню. На карте межстрочный интервал подписей 1.25: три языка в столбик читаются ровнее.
* **Сетка 4 dp:** одинаковое поле 16 dp со всех сторон экрана, шаг 8 dp между блоками, поиск 56, док 64 (8 + 48 + 8), кнопки 48. Скругления «вложенные» (внешний радиус = внутренний + отступ), все размеры вынесены в `values/dimens.xml`.
* **5 цветовых тем** (Меню → «Цветовая тема»), у каждой светлый и тёмный вариант: Океан, Лес, Закат, Лаванда, Графит. Меняют и интерфейс, и карту (земля, вода, растительность, дороги). Меню → «Режим» — светлый/тёмный/как в системе.
* Палитры интерфейса: `res/values/palettes.xml` (светлые) и `res/values-night/palettes.xml` (тёмные); палитры карты: `PALETTES` в `tools/gen_style.py`.

## Навигатор и новое меню (v3.0)
* **Меню** теперь шторка с группами: быстрые кнопки (Навигатор, Точки, Запись, Линейка), разделы «Карта», «Оформление», «Навигация», «Мои данные», «О приложении». Переключатели (рельеф, голос, простые подписи) работают без закрытия меню.
* **Навигатор — полностью офлайн.** Маршруты по дорогам для авто, пешком и на велосипеде строятся по графу из OpenStreetMap (`routing.bin`, собирается в CI скриптом `tools/build_routing.py`). Куда ехать: тап по результату поиска → «Маршрут»; долгое нажатие на карту → «Маршрут сюда»; пункт «Мои точки»; координаты; центр карты.
* Предпросмотр маршрута: расстояние, время, прибытие, переключатель Авто / Пешком / Вело. Во время движения: плашка со следующим манёвром и расстоянием, «круговое: N-й съезд», голосовые подсказки (русский голос телефона), автопересчёт при уходе с маршрута, экран не гаснет.
* Учитываются: односторонние улицы, доступ для транспорта (access/motor_vehicle/foot/bicycle), класс дороги и maxspeed, грунтовки (медленнее), лестницы и тропы (только пешком). **Не учитываются:** запрещающие повороты, платные дороги, пробки, закрытые сезонные перевалы.
* Проверка без телефона: `tools/tests/` (синтетическая карта и проверочная программа для `Router.kt`).

## Компас, кибла и правки (v3.1)
* **Компас** (Меню → «Компас»): циферблат с севером, цель можно выбрать: «Север», «Кибла» или «Пункт…» (поиск по названию населённого пункта/места, из «Моих точек», центр карты, координаты, цель навигатора). Показывает азимут, расстояние и «повернитесь вправо/влево на N°»; при совпадении направления рамка зеленеет и телефон коротко вибрирует. Учитывается магнитное склонение (по вашей позиции, без интернета). Телефон можно держать плашмя (стрелка вперёд по верху экрана) или вертикально (направление задней стороны).
* **Кибла** (Меню → «Кибла»): направление на Каабу по кратчайшему пути (дуга большого круга). Проверено на эталонных городах (Стамбул 151,6°, Лондон 119,0°).
* Переключатель «Поворачивать карту по компасу» разворачивает карту по направлению телефона.
* **Запись трека** сохраняет путь по GPS; после остановки показывается подсказка, где его искать: Меню → «Мои данные» → «Мои треки».
* Выбор цветовой темы и режима теперь не закрывается: после смены цвета окно открывается снова, можно пробовать темы подряд.
* Светлый режим: рамки заметнее (толще и контрастнее). Тёмный режим: подправлены Лес, Закат, Лаванда.
* Логотип MapLibre убран; значок «i» с авторством OpenStreetMap оставлен, этого требует лицензия данных.

## v3.2
* **Калибровка компаса:** при первом открытии (и всякий раз, когда датчик сообщает низкую точность) показывается страница «Калибровка» с анимацией «восьмёрки», шагами, статусом точности и проверкой магнитного поля (норма 25–65 мкТл; вне нормы приложение подсказывает отойти от металла). Стрелка «совпало» и вибрация включаются только при точности не ниже средней. Ссылка «Калибровка компаса» всегда под компасом.
* **Запись трека** теперь кнопка на главном экране (в капсуле справа). Включается/выключается в Меню → «Мои данные» → «Кнопка записи трека»; из меню записи больше нет.
* **Сохранённая точка:** нажатие на неё выделяет её кольцом и открывает панель «Маршрут сюда» / «Маршрут отсюда» (то же для результата поиска и долгого нажатия на карту).
* **Оформление** — один экран: режим (Авто / Светлый / **Сумерки** / Тёмный) и 7 цветовых тем, включая две контрастные: **Контраст** (чёрное-белое, жёлтый в тёмном) и **Неон**.
* **Маршрут без дороги рядом:** берётся ближайшая дорога (до ~45 км), при необходимости пробуются соседние варианты; в предпросмотре указано расстояние до дороги.

## Не включено
* Построение маршрутов по дорогам (офлайн-роутер) — отдельная большая задача.
* Горизонтали рельефа: есть только тени гор.
* Данные OSM актуальны на дату сборки; закрытие горных дорог зимой на карте не отражено.
