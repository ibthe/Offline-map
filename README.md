# Georgia Offline Map (Android)

Полностью офлайн-карта Грузии. В APK нет разрешения INTERNET, все данные внутри.

* Векторные тайлы OpenStreetMap (схема OpenMapTiles) для Грузии, zoom 0–14, дальше масштабируются до 18.
* Подписи на **грузинском, русском и английском**; в приложении кнопка «Языки» включает/выключает каждый язык отдельно.
  Если включено несколько, названия идут столбиком (дубли убираются).
* Рисуются: дороги, тропы, здания, реки, озёра, леса, ледники, заповедники, границы областей, вершины с высотами, населённые пункты, POI.
* Кнопка «Я здесь» — GPS (работает без сети), «Вся Грузия» — вернуть обзор.

## Как собрать

1. Создайте репозиторий на github.com, залейте в него содержимое этой папки (ветка `main`).
2. Вкладка **Actions → Build APK → Run workflow** (или просто push).
3. Первая сборка 20–40 минут (скачивается OSM-выгрузка, строятся тайлы). Дальше данные берутся из кэша.
4. Готовый APK: страница запуска → **Artifacts → georgia-offline-map-apk**. Установите на телефон
   (разрешите установку из неизвестных источников).

При первом запуске приложение один раз распаковывает карту во внутреннюю память (нужно свободное место примерно размером с APK).

## Что внутри

```
.github/workflows/build.yml   сборка: Planetiler -> тайлы, шрифты, style.json, Gradle -> APK
tools/                        генерация стиля, шрифтов, проверка тайлов
app/src/main/java/...         MainActivity (карта, диалог языков), LabelExpr (выражение подписей)
```

## Ограничения

* Названия берутся из OSM (`name:ka`, `name:ru`, `name:en`). Если у объекта нет перевода на выбранный язык, подписи на этом языке не будет.
  Для грузинского запасной вариант — основное поле `name`.
* Рельефа (теней гор и горизонталей) нет — это отдельный растровый слой.
