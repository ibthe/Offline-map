# Georgia Offline Map (Android)

**Текущая версия приложения: 3.4.0.**

Полностью офлайн-карта для поездок по Грузии. В APK нет разрешения INTERNET.

## Что умеет
* Подробная векторная карта OSM (дороги, тропы, здания, реки, леса, ледники, заповедники, границы, вершины с высотами, населённые пункты, POI), светлая и тёмная.
* Подписи на **грузинском, русском и английском**; каждый язык включается отдельно (Меню → Языки).
* **Поиск** городов, сёл, вершин, POI на трёх языках без интернета.
* **Офлайн-навигатор** для автомобиля, пешком, походов и велосипеда: предпросмотр, голосовые подсказки и автоматический пересчёт маршрута.
* **Категории** — плашки на главном экране под поиском: АЗС, аптеки, больницы, банки, магазины, еда, ночлег, вода, туалеты, парковки, вокзалы, остановки, **аэропорты**, достопримечательности, полиция. У каждой категории своя заметная иконка на карте.
* **Рельеф**: тени гор (hillshade) и высота в точке под перекрестием.
* **Высоты** (отдельный слой, Меню → «Высоты»): горизонтали с подписями и вершины с отметками («Кенис 629 м»).
* **GPS без сети** с фильтрацией неточных координат и предупреждением о потере сигнала; **запись трека** в фоне (с уведомлением), **свои точки**, список точек и треков.
* **Линейка**, переход по координатам, копирование координат (тап по строке сверху).
* **Экспорт/импорт GPX** (точки и треки, включая раздельные сегменты и временные отметки); запись автоматически начинает новый сегмент после длительного разрыва GPS.
* **Статистика треков**: расстояние, набор/сброс высоты, общее и активное время, средняя и максимальная скорость.
* **Экспедиция и безопасность**: свежие координаты с точностью, копирование/отправка позиции, быстрый набор 112 и памятка перед выходом.
* **Диагностика** (Меню → Диагностика): размер данных, число тайлов, какие слои реально рисуются, ошибки загрузки.

## Как собрать
1. Залейте содержимое в репозиторий на github.com (ветка `main`).
2. Actions → Build APK → Run workflow. Первая сборка 30–60 минут (тайлы, индекс поиска, рельеф), потом данные берутся из кэша.
3. APK: страница запуска → Artifacts → `georgia-offline-map-apk`.

Сборка проверяет тайлы и валидность кэшированных баз/графа перед повторным использованием. Связанные OSM-данные (тайлы, поиск и роутинг) пересобираются из одного и того же PBF-снимка, чтобы версии не расходились.
Чтобы принудительно обновить OSM-снимок, измените `tools/osm_data_revision.txt`; для обновления рельефа — `tools/terrain_data_revision.txt`. Пользовательский `osm_url` получает отдельный кэш.
При первом запуске приложение распаковывает данные во внутреннюю память. Копирование повторяется только при изменении версии самих картографических данных или повреждении/неполноте файлов, а не при каждом обновлении APK.

* **5 цветовых тем** (Меню → «Цветовая тема»), у каждой светлый и тёмный вариант: Океан, Лес, Закат, Лаванда, Графит. Меняют и интерфейс, и карту (земля, вода, растительность, дороги). Меню → «Режим» — светлый/тёмный/как в системе.
* Палитры интерфейса: `res/values/palettes.xml` (светлые) и `res/values-night/palettes.xml` (тёмные); палитры карты: `PALETTES` в `tools/gen_style.py`.

## Навигатор и новое меню (v3.0)
* **Меню** — шторка с быстрыми действиями «Навигатор», «Компас», «Кибла», «Мои точки», «Линейка» и разделами «Карта», «Оформление», «Навигация», «Мои данные», «О приложении». Запись трека управляется отдельной кнопкой справа; активную запись нельзя случайно скрыть.
* **Навигатор — полностью офлайн.** Маршруты по дорогам для авто, пешком и на велосипеде строятся по графу из OpenStreetMap (`routing.bin`, собирается в CI скриптом `tools/build_routing.py`). Куда ехать: тап по результату поиска → «Маршрут»; долгое нажатие на карту → «Маршрут сюда»; пункт «Мои точки»; координаты; центр карты.
* Предпросмотр маршрута: расстояние, время, прибытие, переключатель Авто / Пешком / Вело. Во время движения: плашка со следующим манёвром и расстоянием, «круговое: N-й съезд», голосовые подсказки (русский голос телефона), автопересчёт при уходе с маршрута, экран не гаснет.
* Учитываются: односторонние улицы, доступ для транспорта (access/motor_vehicle/foot/bicycle), класс дороги и maxspeed, грунтовки (медленнее), лестницы и тропы (только пешком). **Не учитываются:** запрещающие повороты, платные дороги, пробки, закрытые сезонные перевалы.
* Регрессионные тесты маршрутизатора и навигационного прогресса запускаются в GitHub Actions; синтетическая OSM-карта собирается из `tools/tests/make_test_osm.py`. Ручная smoke-проверка доступна через `tools/tests/RouterCheck.kt`.

## Компас, кибла и правки (v3.1)
* **Компас** (Меню → «Компас»): циферблат с севером, цель можно выбрать: «Север», «Кибла» или «Пункт…» (поиск по названию населённого пункта/места, из «Моих точек», центр карты, координаты, цель навигатора). Показывает азимут, расстояние и «повернитесь вправо/влево на N°»; при совпадении направления рамка зеленеет и телефон коротко вибрирует. Учитывается магнитное склонение (по вашей позиции, без интернета). Телефон можно держать плашмя (стрелка вперёд по верху экрана) или вертикально (направление задней стороны).
* **Кибла** (Меню → «Кибла»): направление на Каабу по кратчайшему пути (дуга большого круга). Проверено на эталонных городах (Стамбул 151,6°, Лондон 119,0°).
* Переключатель «Поворачивать карту по компасу» разворачивает карту по направлению телефона.
* **Запись трека** сохраняет путь по GPS; после остановки показывается подсказка, где его искать: Меню → «Мои данные» → «Мои треки».
* Выбор цветовой темы и режима теперь не закрывается: после смены цвета окно открывается снова, можно пробовать темы подряд.
* Светлый режим: рамки заметнее (толще и контрастнее). Тёмный режим: подправлены Лес, Закат, Лаванда.
* Логотип MapLibre убран; значок «i» с авторством OpenStreetMap оставлен, этого требует лицензия данных.

## v3.4
* **Режим «Поход»** в навигаторе: использует пешеходные ограничения доступа, но предпочитает тропы и грунтовые пути; отдельные скорости для троп, дорог и лестниц.
* **Выбор маршрута**: оптимизация по времени («Быстрее») или по расстоянию («Короче»), настройка сохраняется.
* **Точнее учитываются правила OSM**: motorcar, oneway:motorcar, oneway:motor_vehicle, oneway:bicycle и oneway:foot; контрпоточные велодорожки и явные исключения для отдельных видов движения.
* **GPS и треки**: отбрасываются устаревшие/непригодные фиксы для навигации, точная GPS-позиция защищена от подмены грубой сетевой; после 5 минут без точек запись делится на новый сегмент.
* **GPX**: сохраняется отсутствие временных отметок, XML-экспорт очищает запрещённые символы; импорт транзакционный.
* **Экспедиция и статистика**: панель безопасности с координатами и вызовом номеронабирателя 112; статистика расстояния, высоты, времени и скорости.
* **Производительность**: отображаемые треки упрощаются только для карты; исходные точки остаются без изменений в базе и GPX.
* **Пакеты регионов**: введён контракт MapPackage для набора тайлов, поиска, рельефа, горизонталей и графа маршрутизации. Сейчас в реестре доступен только пакет Грузии.
## Ограничения
* Данные OSM — снимок на дату сборки APK; закрытие горных дорог зимой на карте не отражено.
* Навигатор не учитывает запрещающие повороты, условные ограничения доступа, платные дороги, пробки и сезонные закрытия перевалов. Режим «Поход» ориентируется на тип дороги/тропы, но не анализирует уклон, состояние тропы и лавинную опасность.
* Если точка далеко от дороги, маршрут присоединяется к ближайшей подходящей дороге прямым отрезком. Такой участок нужно оценивать на местности; он не означает, что между точкой и дорогой существует проезжий путь.
